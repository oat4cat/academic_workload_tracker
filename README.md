# Трекер академической нагрузки

Для того, чтобы увидеть, что позади, и узнать, что впереди. 

И ещё сразу заметить несоответствия в расписании и нагрузке, если они вдруг случатся.

## Как воспользоваться?

- скачать нагрузку в виде "для печати" (.xlsx файл из Тандема)
- скачать расписание как .csv (с портала, действия - экспорт - CSV)
- скормить всё страничке

Файлы никуда не скачиваются и не передаются, но сохраняются в локальном хранилище браузера. Не забудьте очистить кэш, если работаете на общедоступной машине.
